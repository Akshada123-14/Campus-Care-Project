# Campus-Care-Project
CampusCare – Smart Campus Issue Reporting & Tracking System

Introduction:

CampusCare is a web-based platform developed to simplify campus maintenance and issue management. It allows students to report problems related to campus facilities and enables administrators and maintenance staff to manage, track and resolve issues efficiently.

Key Features:

1. Role-based access for Students, Admins, and Maintenance Staff.

2. Submit and track campus maintenance issues.

3. Assign issues to maintenance staff.

4. Monitor issue status and resolution.

5. Email notifications and dashboard analytics.

6. Integrated chatbot for user assistance and FAQs.

7. Generate and export issue reports.

Technologies Used: Python, Django, HTML, CSS, JavaScript, Bootstrap, SQLite, Gemini API (optional chatbot integration).
